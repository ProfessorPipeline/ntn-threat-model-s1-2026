# Independent student scoring session

The app already records initial ratings and compares F and I separately. It must receive real student judgments. This pack does not fill those fields.

## Before rating

1. Jointly agree on ten suitable case descriptions and all control assumptions.
2. Reject or leave a catalogue record unscored if its conditions cannot support a justified judgment. Add another suitable candidate rather than inventing a score merely to reach ten.
3. Freeze the selected record revisions.
4. Use BLIND_CASES.md for shared descriptions without proposed F/I scores.
5. Use the exact shared F and I criteria shown in Ranking method.

The records and original project examples expose prior scores. If either student has seen those values then record the anchoring limitation. Independence here means each student submits without consulting the other's initial rating. It does not make the exercise a fully blinded experiment.

## Using one agreed database

Use one agreed database for the comparison. Each computer can be checked independently for reproducibility. The scoring exercise can use one presentation computer so the two initial ratings are stored together.

John selects John in Independent scoring and enters an F and I plus a reason for each record. John submits without discussing the values. The initial ratings lock.

Marius selects Marius. John's values remain hidden until Marius also submits for that record revision. Marius enters his own F and I reasons. Do not open the raw evaluation export before both finish because it contains both students' data.

The role selector is a trusted local workflow. It is not identity verification or an access-control system.

## Compare and discuss

- Count complete pairs for the same threat revision.
- F agreement is the number of equal initial F ratings divided by complete pairs.
- I agreement uses equal initial I ratings and the same denominator.
- Do not replace an initial rating with a later agreed score.
- Discuss every difference against a specific written criterion.
- Record the agreed rating and reason plus the deciding criterion.
- Escalate an unresolved difference to the supervisor.

No minimum agreement percentage was supplied. Do not change initial values to make the result look better. Explain the observed disagreement and its implications.
